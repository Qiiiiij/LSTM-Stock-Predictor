# 📈 LSTM-Stock-Predictor

基于 **PyTorch + LSTM** 的股票价格预测系统：自动采集 A 股日线行情 → 数据预处理 → 时序建模训练 → 未来价格预测与可视化；并支持**多源新闻采集与情绪分析**。

## 项目简介

本项目以易明医药（002826）为例，使用东方财富公开行情接口获取日线数据，构建监督学习时序样本后，用三层 LSTM 神经网络同时预测**开盘价**与**收盘价**，并对未来 30 个交易日进行滚动预测。

在此基础上，项目新增新闻情绪分析支线：从**东方财富、新浪财经**双源抓取公司（易明医药/002826）及所在行业（医药/生物医药）的近期新闻，基于**金融情感词典**进行情绪打分（利好/利空/中性），输出情绪报告、每日情绪得分与可视化图表，为股价预测提供舆情参考。

## 功能特性

- **数据采集**：通过东方财富 API 抓取指定股票、指定时间区间的日线行情
- **数据处理**：缺失值前向填充、MinMax 归一化（仅拟合训练集，防数据泄漏）、月度聚合统计
- **模型训练**：3 层 LSTM（hidden_size=128，dropout=0.1），Adam 优化器，300 轮训练，固定随机种子可复现，自动保存模型权重
- **效果评估**：以 RMSE、MAE 衡量训练集与测试集的预测误差
- **滚动预测**：以历史最后 15 天为起点，递归生成未来 30 个交易日价格
- **新闻采集**：东方财富 + 新浪财经双源检索，公司/行业关键词覆盖，自动去重与时间窗过滤
- **情绪分析**：金融情感词典打分（正词/负词/程度副词/否定反转），输出利好/利空/中性标签、正负占比、TOP 新闻；预留 LLM API 接口可升级
- **可视化**：历史价格与预测价格对比图、月度价格趋势图、新闻情绪得分图

## 使用流程

```bash
# 1. 采集股票数据
python collect.py

# 2. 生成月度汇总与趋势图
python process.py

# 3. 训练 LSTM 模型并预测未来 30 天
python lstm.py

# 4. 采集近期新闻（公司 + 行业，双源）
python news_collect.py

# 5. 新闻情绪分析与可视化
python news_analyze.py
```

> 修改 `collect.py` 中的 `stock_code`、`stock_name`、`start_date`、`end_date` 即可切换到其他股票或时间区间。
> 修改 `news_collect.py` 中的 `COMPANY_KEYWORDS` / `INDUSTRY_KEYWORDS` / `DEFAULT_DAYS` 可调整新闻检索范围与时间窗。

## 新闻情绪分析

采用**两档设计**，当前默认本地词典实现，无需联网与第三方 NLP 库：

| 档位 | 实现 | 说明 |
| --- | --- | --- |
| 本地规则（默认） | `DictSentimentAnalyzer` | 基于 `sentiment_dict.py` 金融正负词库打分，支持程度副词加权与否定词反转，输出利好/利空/中性 |
| LLM（预留） | `LLMSentimentAnalyzer` | 抽象接口已定义，填入 DeepSeek/通义等 API Key 并实现调用即可切换 |

输出文件：

- `新闻数据_易明医药_002826.csv`：双源采集的原始新闻（日期/来源/类别/关键词/标题/摘要/链接）
- `新闻情绪分析明细.csv`：逐条新闻的情绪得分与标签
- `新闻情绪每日得分.csv`：按日聚合的日均情绪得分与新闻数量，**可作为后续 LSTM 融合的输入特征**
- `新闻情绪与股价对比.png`：历史收盘价 × 近 30 天每日情绪得分对比图（红涨绿跌）

| 训练轮数 | 300 |

| 训练集比例 | 80% |
