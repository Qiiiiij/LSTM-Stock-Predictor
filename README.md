# 📈 LSTM-Stock-Predictor

基于 **PyTorch + LSTM** 的股票价格预测系统：自动采集 A 股日线行情 → 数据预处理 → 时序建模训练 → 未来价格预测与可视化。

## 项目简介

本项目以易明医药（002826）为例，使用东方财富公开行情接口获取日线数据，构建监督学习时序样本后，用三层 LSTM 神经网络同时预测**开盘价**与**收盘价**，并对未来 30 个交易日进行滚动预测。

## 功能特性

- **数据采集**：通过东方财富 API 抓取指定股票、指定时间区间的日线行情
- **数据处理**：缺失值均值填补、MinMax 归一化、月度聚合统计
- **模型训练**：3 层 LSTM（hidden_size=128，dropout=0.1），Adam 优化器，300 轮训练
- **效果评估**：以 RMSE、MAE 衡量训练集与测试集的预测误差
- **滚动预测**：以历史最后 15 天为起点，递归生成未来 30 天价格
- **可视化**：历史价格与预测价格对比图、月度价格趋势图

## 项目结构

```
LSTM-Stock-Predictor/
├── collect.py                                    # 数据采集（东方财富 API）

└── 易明医药_002826_月度价格趋势.png                  # 月度价格趋势图
```

## 环境依赖

```bash
pip install torch pandas numpy matplotlib scikit-learn requests
```

## 使用流程

```bash
# 1. 采集股票数据
python collect.py

# 2. 生成月度汇总与趋势图
python process.py

# 3. 训练 LSTM 模型并预测未来 30 天
python lstm.py
```

> 修改 `collect.py` 中的 `stock_code`、`stock_name`、`start_date`、`end_date` 即可切换到其他股票或时间区间。

## 模型参数

| 参数 | 取值 |
| --- | --- |
| 输入特征 | 开盘价、收盘价 |
| 时间步长 seq_length | 15 |
| 隐藏层维度 hidden_size | 128 |
| LSTM 层数 | 3 |
| Dropout | 0.1 |
| 训练轮数 | 300 |
| 批大小 | 32 |
| 优化器 / 学习率 | Adam / 0.005 |
| 损失函数 | MSE |
| 训练集比例 | 80% |
